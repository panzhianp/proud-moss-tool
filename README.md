# proud-moss-tool

Data engineer · Scala and Spark · contributing on weekends

## 用法

```bash
cat data.txt | cargo run
```

输出：

```
   3  error: timeout

---

```

## 安装

```bash
git clone https://github.com/USER/proud-moss-tool.git
cd proud-moss-tool
cargo build --release
```
